宽度规则

消息区和输入框共用一个宽度，两侧各留 48px，上下限如下：

  1. 上限 = 屏幕宽 − 800，相当于默认侧栏（264 / 440）下的宽度，收起侧栏不会变宽
  2. 下限 560px，侧栏拖得再宽也不低于它
    • 极窄时两侧至少留 16px
    • Windows 传统滚动条用 scrollbar-gutter 对齐
  3. 空态和有对话时同宽
css
.thread-inner,
.composer-stack {
  /* 两侧 48px，夹在 560 和 屏幕−800 之间 */
  width: min(calc(100% - 32px),
             max(560px, min(calc(100% - 96px), calc(100vw - 800px))));
  scrollbar-gutter: stable both-edges;
}
